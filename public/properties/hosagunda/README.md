# Hosagunda — property images

Drop the real plantation photographs here. Each filename below maps to a labeled
placeholder slot on the page; once the file exists it loads automatically (no code
change needed). Use optimized JPG/WebP, landscape ~1600px wide unless noted.

```
hero.jpg              Hero background (plantation rows / canopy). Portrait-ish ok, ~2000px.
video-poster.jpg      Poster frame for the property video (16:9).
closing.jpg           Final CTA background (wide landscape).
red-soil.jpg          Handful of red soil / soil close-up (4:5 portrait).
water.jpg             Water section — borewell / water point / irrigation / moist plantation (tall/landscape, ~1600px).
masterplan-aerial.jpg Optional aerial photo behind the plot layout (landscape).

crops/arecanut.jpg    Arecanut palms (4:5 portrait).
crops/coffee.jpg      Coffee plants / berries (4:5).
crops/rubber.jpg      Rubber tapping (4:5).
crops/pepper.jpg      Pepper vines (4:5).
crops/coconut.jpg     Coconut palms (4:5).

gallery/areca.jpg     Gallery — areca.
gallery/coffee.jpg    Gallery — coffee.
gallery/rubber.jpg    Gallery — rubber.
gallery/pepper.jpg    Gallery — pepper.
gallery/coconut.jpg   Gallery — coconut.
gallery/red-soil.jpg  Gallery — red soil.
gallery/landscape.jpg Gallery — landscape / surroundings.
```

Do not add categories or crops that don't exist on the land. To add more gallery
images, edit `config/properties.ts` → `hosagunda.gallery`.
